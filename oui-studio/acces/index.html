Copie-le. Colle-le. C'est tout.

oui-studio / PROMPT-DEMARRAGE.md
Bonjour ! Je viens d'acheter le kit « Oui Studio » et je veux créer mon propre agent de motion design, avec son interface, sur cet ordinateur.

Ce dossier contient tout le kit. Lis d'abord BOOTSTRAP.md en entier, puis suis ses étapes dans l'ordre :

05 — Si ça coince

Vérifie tout en une commande.

Et les erreurs les plus courantes, avec leur solution.

Le vérificateur du kit

Dans le terminal, ouvert dans le dossier du kit. Chaque ligne ÉCHEC donne sa solution.

node scripts/verifier-installation.mjs

Tu peux aussi copier le message d'erreur dans Claude Code et lui demander de t'aider.

« claude » n'est pas reconnu, ou « command not found »

Ferme et rouvre le terminal. Toujours pareil :

Windows, dans PowerShell, puis rouvre

$p=[Environment]::GetEnvironmentVariable('PATH','User'); [Environment]::SetEnvironmentVariable('PATH',"$p;$env:USERPROFILE\.local\bin",'User')

Mac, l'une après l'autre

echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
« irm » n'est pas reconnu, ou « The token '&&' is not a valid statement separator »

Tu n'es pas dans le bon terminal : la commande irm va dans PowerShell (pas dans l'invite de commandes CMD).

« Claude Code does not support 32-bit Windows »

Ouvre « Windows PowerShell », pas « Windows PowerShell (x86) ».

L'installation renvoie une page HTML ou une erreur 403

Réseau filtré (entreprise, école, VPN) : essaie depuis une autre connexion.

La connexion échoue ou le navigateur ne s'ouvre pas

Relance claude, puis tape /login. Vérifie que ton abonnement est bien actif (le plan gratuit ne marche pas). Diagnostic :

claude doctor
« node » n'est pas reconnu

Installe Node.js (étape 1), puis ferme et rouvre le terminal et Claude Code.

Mac : « Lancer-interface.command ne peut pas être ouvert »

Clic droit sur le fichier > Ouvrir > Ouvrir. Ou, dans le Terminal du dossier du kit :

chmod +x Lancer-interface.command
L'interface ne s'ouvre pas, ou « port déjà pris »

Elle tourne peut-être déjà : ouvre http://127.0.0.1:4321. Sinon, dans le dossier du kit :

node interface/serveur.mjs --port 4322

puis ouvre http://127.0.0.1:4322.

Le rendu vidéo est très lent ou l'ordinateur rame

Ferme les autres applications (surtout le navigateur). L'agent peut rendre avec moins de puissance (--concurrency=1).

« Limite atteinte » / « usage limit » dans Claude Code

Ta session Claude est épuisée. Attends l'heure indiquée ; ton agent reprendra grâce à projets/<nom>/etat.md.

Toujours bloqué ?Écris-moi, je regarde avec toi.
