03 — Si ça coince

Si ça coince.

Les erreurs les plus courantes, avec leur solution.

Le vérificateur du kit

La fenêtre noire de Demarrer s'en charge à chaque démarrage. Si tu veux la relancer à la main, dans un terminal ouvert dans le dossier du kit : chaque ligne ÉCHEC donne sa solution.

node scripts/verifier-installation.mjs
« claude » n'est pas reconnu, ou « command not found »

Ferme et rouvre le terminal. Toujours pareil, dans le Terminal :

Mac, l'une après l'autre

echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
Windows affiche « Windows a protégé votre ordinateur »

Clique sur Informations complémentaires, puis sur Exécuter quand même. Oui Studio est récent : Windows ne le connaît pas encore.

La clé de licence est refusée

Vérifie qu'elle est copiée en entier (OUI-XXXX-XXXX-XXXX), sans espace autour. Si le studio parle d'un « accès retiré », écris-nous.

L'installation renvoie une page HTML ou une erreur 403

Réseau filtré (entreprise, école, VPN) : essaie depuis une autre connexion.

La connexion à Claude échoue ou le navigateur ne s'ouvre pas

Le studio affiche une alerte rouge « Session Claude Code à reconnecter » : clique sur « Voir comment reconnecter » et suis les étapes. Vérifie aussi que ton abonnement est bien actif (le plan gratuit ne marche pas).

Relance claude, puis tape /login. Vérifie que ton abonnement est bien actif (le plan gratuit ne marche pas). Diagnostic :

claude doctor
« node » n'est pas reconnu

Demarrer te propose de l'installer. Sinon installe la version LTS sur nodejs.org, puis relance Demarrer.

Mac : « Demarrer.command ne peut pas être ouvert »

Clic droit sur le fichier > Ouvrir > Ouvrir. Ou, dans le Terminal du dossier du kit :

chmod +x Demarrer.command
L'interface ne s'ouvre pas, ou « port déjà pris »

Ferme complètement Oui Studio (clic droit sur son icône dans la barre des tâches, puis Quitter), puis rouvre-le. Toujours rien : relance l'installateur par-dessus.

Elle tourne peut-être déjà : ouvre http://127.0.0.1:4321. Sinon, dans le dossier du kit :

node interface/serveur.mjs --port 4322

puis ouvre http://127.0.0.1:4322.

Le rendu vidéo est très lent ou l'ordinateur rame

Ferme les autres applications (surtout le navigateur). L'agent peut rendre avec moins de puissance (--concurrency=1).

« Limite atteinte » / « usage limit » dans Claude Code

Ta session Claude est épuisée. Attends l'heure indiquée ; ton agent reprendra grâce à projets/<nom>/etat.md.

Toujours bloqué ?Écris-moi, je regarde avec toi.

Ce que contient le studio

  • Une installation guidée : tes outils, la connexion à Claude et ton agent prêt, sans prompt à coller.
  • Un agent avec 10 sous-agents (créatif, critique, spectateur, recherche, rendu, son, écoute, plume, scripte, analyse), 31 skills de métier (hooks, sous-titres animés, typographie, direction artistique, Remotion…), 27 modèles de scènes réutilisables et 14 outils d'analyse du son et de l'image.

  • Une clé de licence personnelle (affichée en haut de cette page) et des mises à jour automatiques.

Les mises à jour

Elles sont automatiques. Quand une nouvelle version sort, un bouton « Mettre à jour » apparaît en haut à gauche de ton studio : un clic, il télécharge, remplace les fichiers du kit et redémarre dès que ton agent est au repos. Tes vidéos, ton agent, tes réglages, tes images de référence et tes sons ne sont jamais touchés. Au prochain lancement, une version en attente s'installe d'elle-même.

Si ton studio ne se met pas à jour, ferme-le, rouvre-le, ou retélécharge-le depuis cette page.
